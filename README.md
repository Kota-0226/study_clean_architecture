## Part1 SOLID原則を学ぼう

### 実装要件

システムが満たすべき共通の要件は以下の通りです。Before/Afterどちらの設計であっても、同じ入出力（仕様）を満たす必要があります。

1. 売上データの保持と集計

   - 与えられた売上データ（商品名と金額のリスト）を保持できること。
   - すべての売上の合計金額（Total Sales）を正しく計算できること。

2. CSV出力

   - 保持しているデータから、正しいフォーマットのCSV文字列（ヘッダー付き）を生成できること。

3. PDF出力
   - 保持しているデータから、PDF用のレイアウト文字列（合計金額などを含む）を生成できること。
